# 流向 · 个人财富地图

本地优先的中文个人财务桑基图应用。Node.js 20+，无第三方运行依赖，无需账户或密钥。

```sh
npm start
```

浏览器打开 http://127.0.0.1:3000 。修改 `app.js`、`style.css`、`index.html` 后刷新即可。`PORT=3001 npm start` 可改端口；默认仅监听本机，确需局域网访问可设置 `HOST=0.0.0.0`。

- 资产负债全景、月度现金流、中间向两侧、双向往来四个模板。
- 编辑资金流金额、增删节点、调整节点列与颜色，图表即时更新。
- 图中金额为节点流入或流出较大值；两方向流量分别绘制，不自动抵销。双向模板通过不同节点区分转入转出。
- 总资产和负债独立输入，避免现金流模板错误影响净资产；示例数据仅作演示。
- 自动保存当前方案到浏览器 localStorage；历史快照最多 100 条，可恢复或删除。
- JSON 导入导出当前方案、SVG 导出图表。历史快照保留在当前浏览器中，需要备份时分别恢复并导出。

数据不发送至服务器。更换浏览器、清理站点数据、使用隐私模式或改变访问端口可能无法保留记录，请定期导出 JSON。此应用用于记录，不提供投资建议。

## 验证
